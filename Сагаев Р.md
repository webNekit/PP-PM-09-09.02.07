# Автоматизированная информационная система бронирования гостиничных номеров

## Стек проекта
- **Frontend:** Next.js
- **Backend:** NestJS
- **ORM:** Prisma
- **Аутентификация:** JWT

---

## 1. Назначение системы

Автоматизированная информационная система предназначена для управления процессом
резервирования гостиничных номеров без использования онлайн-оплаты.

Система обеспечивает поиск доступных номеров, создание заявок на бронирование,
управление статусами бронирований и администрирование номерного фонда отеля.

---

## 2. Участники системы

### 2.1 Гость
- Просмотр списка отелей
- Просмотр типов номеров
- Поиск доступных номеров по датам проживания
- Просмотр базовой информации о номерах

---

### 2.2 Клиент
- Регистрация и авторизация
- Создание заявки на бронирование
- Указание данных гостей
- Просмотр статуса бронирования
- Отмена бронирования до подтверждения
- Просмотр истории бронирований

---

### 2.3 Администратор
- Управление отелями
- Управление номерным фондом
- Управление типами номеров
- Просмотр всех заявок на бронирование
- Подтверждение и отклонение бронирований
- Назначение конкретного номера на бронирование
- Изменение дат проживания

---

## 3. Основные сущности системы

- Пользователь
- Отель
- Тип номера
- Номер
- Бронирование
- Гость бронирования
- Статус бронирования
- История изменений бронирования

---

## 4. Функциональные возможности

### 4.1 Каталог отелей и номеров
- Отель содержит описание, адрес и фотографии
- Отель включает несколько типов номеров
- Тип номера определяет вместимость и базовую стоимость
- Конкретные номера привязываются к типу номера

---

### 4.2 Поиск и доступность номеров
- Поиск номеров по датам заезда и выезда
- Проверка пересечения дат бронирований
- Отображение только доступных номеров
- Учет неподтверждённых и подтверждённых бронирований

---

### 4.3 Процесс бронирования
1. Клиент выбирает отель и тип номера  
2. Указывает даты проживания  
3. Заполняет данные гостей  
4. Создает заявку на бронирование  

Статусы бронирования:
- `создано`
- `ожидает подтверждения`
- `подтверждено`
- `отклонено`
- `отменено`

---

### 4.4 Управление бронированиями
- Клиент может:
  - просматривать статус бронирования
  - отменять бронирование до подтверждения
- Администратор может:
  - изменять статус бронирования
  - назначать номер
  - изменять даты проживания

---

### 4.5 Авторизация и роли
- JWT-аутентификация
- Роли пользователей:
  - клиент
  - администратор
- Ограничение доступа к API по ролям

---

## 5. API (логические модули)

### Auth
- Регистрация пользователя
- Авторизация
- Обновление access-токена

### Hotels
- Получение списка отелей
- Получение информации об отеле

### Rooms
- Получение типов номеров
- Получение доступных номеров по датам

### Bookings
- Создание бронирования
- Изменение статуса бронирования
- Отмена бронирования
- Просмотр бронирований пользователя

---
